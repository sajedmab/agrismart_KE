# AgriSmart_KE
 
Application Flutter de suivi et d'irrigation d'une exploitation agricole (Kébili) — mini-projet Atelier Framework Cross-Platform, ISET Kébili.
 
## Fonctionnalités
 
- Authentification Firebase (connexion, inscription, mot de passe oublié)
- Zones d'irrigation (ajout, modification, suppression) avec historique des irrigations
- Météo avec cache hors ligne
- Statistiques et export des rapports (PDF / CSV)
- Diagnostic de plante par photo (ML Kit Image Labeling)
- Journal des activités
- Thème clair / sombre et données enregistrées sur l'appareil (par utilisateur)
## Lancement
 
```bash
flutter pub get
flutter run
```
